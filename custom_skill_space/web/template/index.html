问题

教学智能体正在盲答

每个备课/组卷/诊断工具都在临时拼凑课标知识。没人真正核对过：这条要求原文怎么写、 它属于哪个年级、它的前置在哪里。

编号会被臆造

模型知道课标编号长什么样，于是按规律造出 5.NF.9 这种并不存在的条目——形式对，内容假。

年级会被拉平

「解一元一次方程」到底是 4 年级还是 6 年级，参数里没有清晰边界，越级教学因此发生。

没有前置拓扑

「异分母加减依赖等值分数原理，而后者又依赖分数即单位分数之和」——这种链路没有任何地方记着。

检索停在文档

PDF 全文检索只能定位页码，给不出「这个 domain 在相邻年级如何递进」的结构答案。

方法

如何构建课标图谱

一条 8 段式流水线，把一张 Excel 表淬炼成可计算的拓扑与可被 agent 调用的技能。

阶段一 · 图谱构建
01

表格解析

读 数学课标整理表格.xlsx：年级/领域/知识点/要求/编号/页码六列。

02

合并单元格填充

年级与领域只在首行有值，向下填充补齐，否则 385 条里大半会丢失归属。

03

编号归一

K.CC.4 与 S-MD.5 两套编号体系统一成主键，高中五个概念类别单列。

04

结构推导边

同 cluster 串链、同 domain 相邻年级相连、8 年级桥接到高中类别——共 1208 条。

阶段二 · 技能与校验
05

两级加载

SKILL.md 只写「怎么查」，385 条全量留在 CSV 里按需 grep，上下文不被撑爆。

06

回答约定

强制给原文、年级、领域与 PDF 页码；表里没有的直说没有，不许按规律臆造。

07

自动回表核对

抓回答里的编号逐个回 CSV 查，一个都对不上就判失败——这就是幻觉的度量。

08

结果落盘

每次运行留元数据、最终回答、完整 session history 与原始事件流，可复查可复现。

校验

幻觉是可测量的

最近一次全量运行：15 个用例全部通过。回答里出现的课标编号被逐个回表核对—— 237 次引用、139 个去重编号，全部命中，没有一个是臆造的。

另有 21 个形如 5.NF.4b、6.RP.3c 的 子项引用：a/b/c 子条目写在 requirement 正文里、表中不单独成行，父编号存在即为有效。 校验器最初把它们误判成表外编号，现已单列一类——这类误判本身也是校验口径的一部分。

判据写死在脚本里：从回答正文抽出 5.NF.1 / S-MD.5 这种形态的编号，逐个 grep '^<code>,' 回 CSV。对不上就是 FAIL，没有中间地带。

面向教师与智能体

为任意教学系统注入结构化课标

技能包就是接口：agent 用 read / bash 读取，人用 grep / awk 查询，同一份数据两种消费方式。

# 按编号取一条（行首匹配最准） grep -m1 '^8.G.7,' references/standards.csv # 某年级某领域全部条目 awk -F',' '$2=="5"' references/standards.csv \ | grep ',Number and Operations—Fractions,' # 关键词反查编号 grep -i 'pythagorean' references/standards.csv \ | cut -d',' -f1,2,5
// standards.json 的节点结构 { "code": "8.G.7", "grade": "8", "domain": "Geometry", "cluster": "Understand and apply the Pythagorean Theorem.", "requirement": "7. Apply the Pythagorean Theorem to determine unknown side lengths in right triangles…", "pdf_page": "P56" }
