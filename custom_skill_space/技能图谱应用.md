# 技能图谱应用：一级分类与 prompt 设计

这张技能图谱只有一件事实基础：**385 条课标，每条带编号、年级、领域、cluster、要求原文、PDF 页码**。
所有应用都是这六列的不同用法——想清楚「输入是什么、要回表查什么、输出怎么核验」，
应用分类就自然分出来了。

下面五个一级分类按**输入形态**划分，互不重叠：

| ID | 一级分类 | 输入 | 输出 | 回表方向 |
| --- | --- | --- | --- | --- |
| A1 | [知识点阐释](#a1-知识点阐释) | 编号 / 年级 / 领域 | 课标原文 + 解读 + 页码 | 编号 → 内容（正查） |
| A2 | [知识点识别与对齐](#a2-知识点识别与对齐) | 题目 / 教案 / 课件文本 | 命中的编号 + 依据 + 置信度 | 内容 → 编号（反查） |
| A3 | [学情诊断与补救](#a3-学情诊断与补救) | 错题记录 / 答题表现 | 薄弱编号 + 前置链 + 补救顺序 | 编号 → 纵向前置 |
| A4 | [教学设计与课程规划](#a4-教学设计与课程规划) | 年级 + 单元 + 课时数 | 教学序列，每课时挂编号 | 编号集合 → 排序 |
| A5 | [命题与评估](#a5-命题与评估) | 编号集合 + 题量/题型 | 题目 + 评分要点 + 双向细目表 | 编号 → 可测行为 |

三条贯穿所有分类的硬约束（已写进 `SKILL.md` 的「回答约定」）：

1. **编号必须能回表核对**——`grep '^<code>,' references/standards.csv` 查得到才算数，按编号规律臆造的一律不认。
2. **输出带 `grade` / `domain` / `pdf_page`**——页码是回到原始 PDF 复核的锚点。
3. **表外的事说不知道**——表里没有教材、题库、学生数据、课时安排，凡是要这些的部分应显式标注「需外部输入」。

## A1 知识点阐释

**做什么**：把编号或范围翻译成人能用的东西——原文、中文解读、所属 cluster、页码。
这是最基础的一类，也是其它四类的公共子步骤。

**典型场景**：备课前确认某条课标到底要求到什么程度；跟家长/学生解释某个知识点的官方定位。

**依赖列**：全部六列。

### Prompts

```bash
# A1-P1 单条精确查询（已验证）
SKILL_PROMPT='用 math-standards 技能查一下课标编号 8.G.7 和 K.CC.4：分别给出课标要求原文、所属年级与领域、以及 PDF 页码。' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A1-P2 领域全量列举（已验证）
SKILL_PROMPT='查一下 5 年级 Fractions 领域有哪些课标' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A1-P3 分层解读：同一条课标讲给三种人听
SKILL_PROMPT='取课标 6.RP.3，先给原文和页码，再分别用三种口径解释它要求学生会什么：给学生的一句话、给家长的一句话、给老师的可观察行为清单（每条以动词开头）。不要脱离原文加码。' bash custom_skill_space/create_and_run_skill.sh
```

**验收要点**：编号、页码能回表对上；解读不超出 `requirement` 原文的范围（不加码也不缩水）。

## A2 知识点识别与对齐

**做什么**：反方向——给一段教学内容（题目、教案、课件、视频转录），判断它对应哪些课标编号。
PDF 里那个空着的「知识点识别」就是这一类。

**典型场景**：给自研题库/讲义打课标标签；核对一节课到底覆盖了哪些标准、有没有越级。

**依赖列**：`requirement` + `cluster` 用来匹配语义，`code` / `grade` 用来输出。

### Prompts

```bash
# A2-P1 单题打标签（含置信度与排除理由）
SKILL_PROMPT='给下面这道题打课标标签：一个长方形的长是 3/4 米，宽是 2/3 米，求面积。要求：列出最匹配的 1-3 条课标编号，每条给出原文、年级、页码，说明判定依据（题目的哪个特征对应课标的哪句话），并给出高/中/低置信度；再列出一条你考虑过但排除的编号及排除理由。' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A2-P2 教案覆盖度审计
SKILL_PROMPT='这是一节 7 年级课的教学要点：1 用比例关系解决折扣问题；2 由两个量的表格判断是否成正比例；3 求比例常数并写出方程。请逐条对齐到 Common Core 课标编号，输出表格（要点 | 编号 | 原文 | 页码 | 对齐强度）；最后指出这节课覆盖了该 cluster 的哪几条、还漏了哪几条。' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A2-P3 年级适配性检查（是否越级）
SKILL_PROMPT='一位老师想在 4 年级课上讲「用字母表示未知数并解一元一次方程」。请回表判断：这个内容在课标里落在哪个年级的哪条编号上，4 年级本身有哪些相关课标，二者差距在哪。结论明确说是否越级，并给出 4 年级可以做的铺垫（只能引用表里真实存在的编号）。' bash custom_skill_space/create_and_run_skill.sh
```

**验收要点**：给出的编号必须回表存在；`grade` 与题目声称的年级不一致时要显式说明（越级/降级都是有效结论）。
**需外部输入**：真实题库或教案文本——一次性模式下直接粘进 prompt，量大时改成让它读文件（见文末「换成真实数据」）。

## A3 学情诊断与补救

**做什么**：从学生的错误表现出发，定位薄弱课标，再沿**年级纵向**追前置知识，给出补救顺序。
表里的 `grade` 列让「前置链」可以被检索，而不是凭印象。

**典型场景**：单元测评后的错因归类；一对一辅导前定起点。

**依赖列**：`code` / `grade` / `domain` / `requirement`（前置链靠同 domain 跨 grade 检索）。

### Prompts

```bash
# A3-P1 错题 → 薄弱编号 → 前置链
SKILL_PROMPT='一名 5 年级学生的错题表现：1 计算 2/3 + 1/4 时直接分子加分子、分母加分母；2 判断 3/4 × 5 的结果比 5 大还是小时答不上来；3 应用题里把「1/2 米的 1/3」列式为 1/2 ÷ 1/3。请回表定位这三处各违反了哪条课标（给编号、原文、页码），再沿同一 domain 往低年级追出前置课标链（列出编号与年级），最后给一个从最底层前置开始的补救顺序。只引用表里真实存在的编号。' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A3-P2 掌握度画像（按 cluster 汇总）
SKILL_PROMPT='某 3 年级班级测评结果：乘除法应用题正确率 45%，分数初步认识 78%，面积与周长 60%，数据表格读取 85%。请把这四项各自对齐到 3 年级的 cluster 与课标编号，按正确率排出优先干预顺序，并说明每项若不干预会影响到 4 年级的哪几条课标（给编号和年级）。' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A3-P3 纵向进阶追踪（某主题 K→高中）
SKILL_PROMPT='沿年级追踪「分数与比例推理」这条主线：从 K 到高中，逐年级列出该主线上的关键课标编号与一句话要求，画出一条演进链，并标出其中三个最容易断档的衔接点（说明断在哪两条编号之间、为什么）。只用表里存在的编号。' bash custom_skill_space/create_and_run_skill.sh
```

**验收要点**：前置链里的编号年级必须**单调不增**（前置不能比目标年级高）；断档点要指名具体两条编号。
**需外部输入**：真实答题数据。表里没有难度、区分度、常见错误类型，这些结论只能来自你给的表现描述。

## A4 教学设计与课程规划

**做什么**：给定范围和课时预算，把课标集合排成一条可执行的教学序列，每课时挂编号。

**典型场景**：学期教学计划；专题复习课排布；插班生补课方案。

**依赖列**：`grade` / `domain` / `cluster`（cluster 天然是「一组该一起教的课标」）/ `code`。

### Prompts

```bash
# A4-P1 单元教学序列
SKILL_PROMPT='为 6 年级 Ratios and Proportional Relationships 这个 domain 设计一个 8 课时的教学序列。要求：先列出该 domain 下的全部课标编号与原文，再排 8 课时，每课时写明覆盖的编号、教学目标（可观察行为）、以及它依赖前面哪一课时。最后说明有没有课标被挤掉，为什么。' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A4-P2 跨年级衔接课（暑期过渡）
SKILL_PROMPT='设计一个 5 升 6 的暑期过渡方案，共 6 次课。请回表选出：5 年级里必须夯实、否则会拖累 6 年级的课标（给编号和它拖累的 6 年级编号），以及 6 年级开学前值得先铺垫的课标。按 6 次课排布，每次课注明「巩固」还是「铺垫」及对应编号。' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A4-P3 课时预算不足时的取舍
SKILL_PROMPT='4 年级 Number and Operations in Base Ten 只剩 4 个课时，但该 domain 的课标条目不止 4 条。请列出全部条目，按「后续年级依赖它的程度」排序（依赖关系必须用表里真实的编号说明），给出 4 课时的取舍方案，并明确列出被舍弃的编号和风险。' bash custom_skill_space/create_and_run_skill.sh
```

**验收要点**：课时表里每个编号都能回表；被舍弃的条目要显式列出，不能悄悄漏掉。
**需外部输入**：教材章节、班级实际进度、课时长度——表里没有，方案只是课标层面的骨架。

## A5 命题与评估

**做什么**：由课标编号生成可测的题目、评分要点和双向细目表，保证每道题都能回溯到编号。

**典型场景**：单元测验组卷；作业设计；给已有试卷做课标覆盖度体检。

**依赖列**：`requirement`（里面的动词就是可测行为）+ `code` / `grade`。

### Prompts

```bash
# A5-P1 按编号命题（含评分要点）
SKILL_PROMPT='为课标 7.EE.4 命 3 道题：一道直接应用、一道情境应用、一道容易暴露常见误解。每题给出题干、参考答案、评分要点（哪一步给分），并逐题说明它测的是原文里的哪个动词/短语。先给出该编号的原文和页码。' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A5-P2 单元卷双向细目表
SKILL_PROMPT='为 3 年级 Operations and Algebraic Thinking 设计一份 10 题的单元测验双向细目表：表格列为 题号 | 课标编号 | 认知层次（记忆/理解/应用/分析）| 分值 | 考查的原文依据。要求覆盖该 domain 的全部 cluster，说明每个 cluster 分到几题以及为什么。' bash custom_skill_space/create_and_run_skill.sh
```

```bash
# A5-P3 已有试卷的覆盖度体检
SKILL_PROMPT='一份 8 年级期中卷的考点清单：1 解一元一次方程；2 一次函数图像与斜率；3 勾股定理求边长；4 散点图与趋势线；5 平方根估算。请逐项对齐课标编号（给原文和页码），统计覆盖了 8 年级哪几个 domain、每个 domain 几题，指出完全没考到的 domain 及其编号，并给出补题建议。' bash custom_skill_space/create_and_run_skill.sh
```

**验收要点**：每道题都挂着一个真实编号；细目表里的 cluster 划分要与表里的 `cluster` 列一致。
**需外部输入**：难度定标、学生水平、考试时长。

## 怎么挑分类：一句话判据

- 手里是**编号** → A1
- 手里是**内容**（题目/教案），要找编号 → A2
- 手里是**学生表现** → A3
- 手里是**时间预算** → A4
- 要产出**测量工具** → A5

## 换成真实数据

一次性模式（`-p`）适合把样例直接写进 prompt。数据量大时让 agent 自己读文件——
它有 `read` / `bash` 工具，工作目录是仓库根：

```bash
SKILL_PROMPT='读 custom_skill_space/source/我的错题记录.md，按 A3 的方式定位薄弱课标编号、追前置链、给补救顺序。' bash custom_skill_space/create_and_run_skill.sh
```

需要多轮追问（比如先定位再细化方案）时，别用一次性模式，直接进交互：

```bash
bash piagent_space/install_run_piagent.sh --skill custom_skill_space/math-standards
```

## 跑重 prompt 前：输出上限

A3/A4/A5 这类要「查表 + 推理 + 成篇输出」的 prompt，模型会先写很长一段 thinking。
provider 的 `maxTokens` 太小的话，思考写满就 `stopReason=length`，正文一个字都出不来——
表现是脚本跑完**什么回答都没有**，自检报「没有能对上表的课标编号」。

`install_run_piagent.sh` 现在默认给到 32000（原来 8000 就踩过这个坑，A3-P1 首次实跑
thinking 写了 24k 字符被截断）。要调：

```bash
PIAGENT_MAX_TOKENS=64000 SKILL_PROMPT='...' bash custom_skill_space/create_and_run_skill.sh
```

判断是不是撞了这条限制：看最新 session 里最后一条 assistant 消息的 `stopReason`。

```bash
ls -t piagent_space/sessions/*.jsonl | head -1 | xargs grep -o '"stopReason":"[a-z]*"' | tail -1
```

## 自动校验说明

`create_and_run_skill.sh` 跑完会自检 skill 有没有真的被加载：

- 默认 prompt：检查 `Pythagorean` / `P56` / `P11` 三个只有查表才知道的标记。
- 自定义 prompt（上面这些都是）：从回答里抽出课标编号（`5.NF.1`、`8.G.7`、`S-MD.5` 这种形态），
  逐个回 `standards.csv` 核对，**至少一个能对上**才算通过——所以上面每条 prompt 都要求「只引用表里真实存在的编号」，
  这既是质量要求，也是让自检能判定的前提。
